# Contributing

Thank you for improving the API Security Maze.

1. Keep all examples defensive and non-operational.
2. Preserve the simple learning loop: choose an enemy, equip a defense, play, read the result.
3. Do not add analytics, trackers, external fonts, CDNs, or runtime network calls.
4. Keep blue maze rails outside the yellow travel lane.
5. Update `src/arcade.html`, then run `npm test` to regenerate and validate `site/`.
6. Include an authoritative source when changing security guidance.
7. Keep the original artwork and non-affiliation notice intact.

Do not submit secrets, private system details, customer data, or exploit automation.
