# Security policy

## Reporting a problem

Please use GitHub’s private vulnerability-reporting feature for security issues in this educational site. Do not include real credentials, private customer data, or attack traffic in a report.

This project is a local browser simulation. It intentionally makes no API calls, collects no analytics, stores no credentials, and sends no attack traffic. Its examples explain defensive concepts and are not a security scanner or certification tool.

## Supported version

The latest deployment from `main` is supported. Older commits and forks may not contain current fixes.
